# Django-NB Project Context

## Project Overview
A Django application with Nginx reverse proxy support, multi-language interface, and AI chat capabilities.

## Key Technologies
- **Framework**: Django 6.0.8
- **Database**: SQLite (db.sqlite3)
- **Server**: Nginx reverse proxy
- **AI Integration**: Ollama (LLM model configured via OLLAMA_MODEL env var)
- **API**: Django REST Framework

## Internationalization
- **Languages**: English (en) and German (de)
- **Locale Path**: `locale/`
- **Cookie Domain**: Dynamically set from ALLOWED_HOSTS to support both `domain.com` and `www.domain.com`
- **Cookie Age**: 1 year

## Deployment
- **Production Hosts**: Read from `.env` ALLOWED_HOSTS (comma-separated, supports both `domain.com` and `www.domain.com`)
- **Development Hosts**: localhost, 127.0.0.1, [::1] (when DEBUG=true)
- **Media Root**: BASE_DIR (with security TODO: move to dedicated media/ directory)
- **Static Files**: `/static/` URL, collected to `staticfiles/` directory
- **News Static Files**: Located in `news/` directory

## Core Features
1. **Chat Function**: Ollama-powered AI chat integration
2. **User Contact Methods**:
   - Schedule a meeting/appointment
   - Send messages
3. **Admin Panel**: Django admin interface
4. **REST API**: Django REST Framework support
5. **Authentication**: Django built-in auth system

## Important Settings
- **SECRET_KEY**: Required, must be set in `.env` (raises ImproperlyConfigured if missing)
- **DEBUG**: Controlled by env var, defaults to False
- **CORS/Security**: NoIndexMiddleware applied for SEO control
- **Logging**: Rotating file handler to `logs/app.log` (5MB per file, 5 backups)

## File Structure
- `config/settings.py` - Main settings
- `config/urls.py` - URL routing
- `webapp/` - Main app with models, views, middleware, context processors
- `locale/` - Translation files
- `logs/` - Application logs
- `staticfiles/` - Collected static files
- `db.sqlite3` - SQLite database

## Environment Variables Required
- `SECRET_KEY` - Django secret key (mandatory)
- `ALLOWED_HOSTS` - Comma-separated list (e.g., "domain.com,www.domain.com")
- `DEBUG` - Boolean (0/1, true/false, yes/no, on/off)
- `OLLAMA_MODEL` - LLM model name (default: "llama3.2:1b")
